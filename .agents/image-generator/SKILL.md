# ComfyUI CG Generator Skill

このスキルは、ユーザーの指示、または連携するシナリオエージェントからのリクエストを受け取り、ローカル環境で稼働するComfyUI APIを利用して、美少女ゲーム/エロゲに特化したイベントCG（HCG含む）を生成します。

## When to use this skill

- ゲーム内の特定のシーン（イベントCG）の画像が必要になった時。
- シナリオエージェント（`scenerio-writer`など）から、`imageFile` タグによって画像生成リクエストが行われた時。
- ユーザーからキャラクターの特徴やシチュエーションを提示され、CGの「仕様書」を作成し、画像を生成する必要がある時。
- 1つのベースCGから、表情、服装、液体などの「差分」を生成する必要がある時。

## How to use it

以下の手順と原則に従って、ComfyUIへのリクエスト（プロンプト構築）を行ってください。

### 1. 情報収集と内部仕様書の作成（鉄則）
画像を生成する前に、必ず以下の「仕様書」項目を内部的に確定させてください。シナリオからのリクエストの場合は、文脈からこれらを抽出してください。

- **登場キャラクター**: 特徴、服装、状態。
- **シーンテーマ**: そのCGが伝えるべき一言の感情（例：「屈辱」「とろけるような快感」）。
- **場所と光源（最重要）**: 光源の位置（逆光、窓からの夕日、スポットライトなど）を具体的に指定し、プロンプトの優先度を上げてください。
- **構図**: 原則として**プレイヤー主観（POV）**。主人公は映さないか、手や体の一部のみ。キスシーンならドアップ。
- **必要な差分リスト**: 表情（通常→アヘ→絶頂）、脱衣段階、液体（愛液、精液、汗）。

### 2. プロンプト構築ロジック（エロゲ塗り・表現の徹底）
ComfyUIに投げるプロンプトには、以下のエッセンスを必ず盛り込んでください。

- **画風（エロゲ塗り）**: `game cg`, `digital painting`, `highly detailed eyes`, `transparent skin`, `glossy clothing`, `anime style` などのタグを用い、肌の透明感、服の光沢、髪のハイライトを強調する。線画は `clean lines` を意識。
- **粘性・湿潤性の徹底**: 性的シーン、またはその直前・直後の場合、`sweat`, `saliva`, `wet`, `glistering`, `viscous fluids` などのタグを多用し、乾いた表現を排除する。
- **超接写（Micro Pulse連携）**: 性的部位や表情にフォーカスする場合、`extreme close-up`, `macro shot`, `focus on face/crotch` を指定。

### 3. ComfyUI APIとの連携テクニック
- **エンドポイント**: `http://127.0.0.1:8188/prompt`
- **ワークフローの選択**: 要望（立ち絵、イベントCG、HCG、または特定のモデル）に応じて、適切なComfyUIのワークフローJSONを選択・カスタマイズして送信してください。
- **差分生成（Layer管理）**: 差分が要求された場合、ComfyUI内での生成において、SAM3によるマスキングや、ポーズの固定（ControlNetの使用など）を徹底し、表情や液体レイヤーのみが変化するようにパラメーターを制御してください。

### 4. 出力とフィードバック
- 出力サイズは1344x768を基本とする。`cutIn`の場合は1024x1024の正方形で生成。
- 生成された画像ファイル（またはBase64データ）を受け取り、システム（Tauriエディタ等）に返却してください。

## 内部リファレンス：エロゲCG制作哲学（ComfyUI変換用）

このスキルが生成する画像は、以下の哲学に準拠しなければならない。

1.  **枚数よりインパクト**: 1枚のクオリティと、そこから生まれる差分の多様性が命。
2.  **主観視点（おれ視点）**: プレイヤーがその場にいる没入感を最優先。カメラは産毛が見える距離まで寄る。
3.  **光源が雰囲気を決める**: ライティングの指定（プロンプトでの強調）を怠らない。
4.  **ぬらぬら感**: 液体、光沢、滴りの表現（湿潤性）を視覚化。

## ComfyUI Request Schema (Expected JSON Structure to API)
- resources/AnimaWorkflow.json: Anima previewモデルを使って画像生成を行うシンプルなワークフロー
- resources/AnimaWorkflow_with_lora.json: Anima previewモデルにLoRAを適用して画像生成を行うワークフロー
- resources/SAM3AnimaMaskWorkflow.json: SAM3を使ってプロンプトで指示した部分をInpaintingするワークフロー
- resources/SAM3MaskWorkflow_lora.json: SAM3を使ってプロンプトで指示した部分をInpaintingするワークフロー(LoRA適用)
