# Irodori-TTS Voice Synthesis Skill

このスキルは、ゲームシナリオ内のセリフ（特に感情の乗った「鏡流」テキスト）を音声化するためのエージェントです。リファレンス音声（WAV）に基づき、キャラクターの個性を維持したまま、文脈に即した発話を生成します。

## When to use this skill

- `scenerio-writer`（または他のシナリオエンジン）が、ボイス付きのセリフ（`voice`タグ）を生成した時。
- シナリオ制作の「Planning」フェーズにおいて、登場キャラクターに最適な「リファレンス音声（RefWav）」を割り当てる必要がある時。
- 生成されたシナリオファイルに基づき、実際の音声リソースを一括、または逐次生成する時。

## How to use it

### 1. プランニングとマッピング（RefWavの選択）
音声を生成する前に、エージェントは以下のマッピングテーブル（またはそれに準ずる設定）を確定させてください。
- **Character**: キャラクター名（例：ライラ）
- **Ref-Wav Path**: そのキャラクターの「魂」となるリファレンス音声のパス（例：`assets/ref/laila_calm.wav`）
- **Emotion Adjust**: シナリオのフェーズ（序盤・中盤・終盤）に応じて、リファレンス音声を切り替える（例：静止時は「冷静」、絶頂時は「激昂」のRefWavを選択）。

### 2. テキストの最適化
Irodori-TTSの性能を引き出すため、シナリオエンジンのテキスト（`っ`、`……`、`！`）をそのまま活かしつつ、必要に応じて読みを調整してください。
- 鏡流の「マイクロ・パルス（溜め）」を音声の「間」として表現できるよう、テキストの区切りを意識します。

### 3. 音声生成コマンドの実行
以下のテンプレートを用いて、ローカル環境のコマンドラインを実行します。

```bash
cd F:\\repo\\Irodori-TTS; uv run python infer.py  --hf-checkpoint Aratako/Irodori-TTS-500M-v2  --text "{text}" --ref-wav {path_to_ref_wav}  --output-wav {output_path}
```
